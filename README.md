# Food Delivery Platform

A production-grade food delivery platform built using Java, Spring Boot,
Microservices, MySQL, Redis, Kafka, Docker, Kubernetes, and AWS.

## Architecture

Microservices architecture.

### Services

- API Gateway
- User Service
- Restaurant Service
- Menu Service
- Cart Service
- Order Service
- Payment Service
- Delivery Service
- Notification Service

## Technology Stack

- Java 25
- Spring Boot
- Spring Data JPA
- MySQL
- Redis
- Apache Kafka
- Docker
- Kubernetes
- Prometheus
- Grafana
- OpenTelemetry
- AWS
